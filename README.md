# Context Menu Tool

![Context Menu Tool](https://img.shields.io/badge/Version-1.0.1-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%2010/11-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**A powerful and intuitive tool to customize your Windows right-click menu in seconds.**

Add your favorite applications, tools, and shortcuts directly to File Explorer for instant access. No more digging through Start Menu or searching for apps - everything you need is just a right-click away.

---

## Features

### 🚀 Lightning Fast Access
Add any application directly to your right-click context menu. Open your favorite tools instantly from any file, folder, or desktop.

### 📁 Multiple Context Types
- **File Menu** - Right-click on any file
- **Folder Menu** - Right-click on any folder
- **Background Menu** - Right-click on empty space on desktop

### 🎨 Modern & Clean
Sleek dark interface designed for Windows 11 with smooth animations and intuitive navigation.

### 📦 Batch Operations
Select and add multiple apps at once. No repetitive clicks.

### 🔍 Smart Search
Find any installed application instantly with built-in search.

### 🛡️ Safe & Simple
Visual indicators show which apps are already added. Easy to remove entries with one click.

## Getting Started

### Installation

1. Download the latest installer from the [Releases](https://github.com/sapariyaneel/Context-Menu-Tool/releases) page
2. Run the installer
3. Accept the license agreement
4. Click Install
5. Done!

### Usage

1. **Launch the app** - Find it in Start Menu or double-click the desktop shortcut
2. **Browse apps** - Use grid or list view to see all installed applications
3. **Search** - Type the app name to find it quickly
4. **Choose location** - Select where to add (File, Folder, or Background)
5. **Add** - Click "Add Selected" to add apps to context menu

That's it! Your apps are now available in the right-click menu.

## Why Context Menu Tool?

- **No Learning Curve** - Simple, intuitive interface anyone can use
- **No Configuration** - Works out of the box
- **No Dependencies** - Self-contained, no .NET or other runtime needed
- **No Clutter** - Shows only user-installed apps, not system utilities
